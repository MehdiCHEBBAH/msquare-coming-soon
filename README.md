# MSQUARE - Coming Soon

A modern, responsive coming soon page for MSQUARE - Your destination for 100% original shoes.

## Features

- 🎨 Modern design inspired by MSQUARE branding
- 📱 Fully responsive for all devices
- ✨ Smooth animations and hover effects
- 🚀 Fast loading and optimized
- 📧 Email subscription form
- 🎯 SEO optimized

## Design Elements

- **Color Scheme**: Dark gray (#1a1a1a), white, and vibrant orange (#ffa500)
- **Typography**: Inter font family for clean, modern look
- **Layout**: Grid-based responsive design
- **Animations**: Floating elements and smooth transitions

## Deployment

This website is designed to be deployed on GitHub Pages. Simply:

1. Push your code to a GitHub repository
2. Enable GitHub Pages in repository settings
3. Select the main branch as source
4. Your site will be available at `https://yourusername.github.io/msquare-coming-soon`

## File Structure

```
├── index.html          # Main HTML file
├── styles.css          # CSS styles
└── README.md           # This file
```

## Customization

To customize the website:

1. **Colors**: Modify the CSS variables in `styles.css`
2. **Content**: Update text content in `index.html`
3. **Branding**: Replace logo and brand elements
4. **Features**: Add or remove sections as needed
